# Meeting Recorder & Gemini Model Tester 🎙️🔍

這是一個基於純前端技術（HTML/JS/CSS）開發的語音工具箱，旨在協助使用者進行會議錄音，並利用 Google Gemini API 進行高效的語音轉文字（Speech-to-Text）處理與模型測試。

## 📁 專案結構與模組

本專案包含以下核心網頁工具：

1. **`AI meeting-recorder-v7.html`** (會議記錄主程式)
   * 專案的核心錄音與轉錄工具。
   * 可直接整合並套用測試通過的 Gemini 模型，進行即時或後續的會議音訊轉錄。

2. **`gemini-model-tester.html`** (Gemini 模型語音測試工具)
   * 協助測試與篩選最適合用於語音轉錄的 Gemini 模型的輔助工具。
   * 自動列出所有 API Key 可用的模型，並對其進行多模態語音測試。

---

## 🛠️ Gemini 模型測試工具功能特色 (`gemini-model-tester.html`)

* **自動載入可用模型**：支援 `v1` 與 `v1beta` 版本的 API，一鍵列出您帳號目前可存取的所有 Gemini 模型。
* **智慧音訊支援偵測**：基於模型家族（如 Gemini 1.5, 2.0, 2.5 系列）與關鍵字，自動判定該模型是否「支援音訊」、「可能支援」或「不支援」。
* **拖放式音訊測試**：
  * 支援拖放或點選上傳本地音訊檔（支援 MP3, WAV, WebM, M4A, OGG 等常見格式）。
  * 自動在瀏覽器端轉換成 Base64 編碼發送請求，確保完全的隱私與安全性。
* **單獨與批次測試**：
  * **單獨測試**：一鍵針對特定模型發送測試音訊並查看轉錄結果。
  * **文字測試**：若無提供音訊檔，可進行純文字可用性測試。
  * **批次測試**：自動排隊測試所有標記為支援或可能支援的模型，並內建 800ms 延遲以避免觸發 Rate Limit 限流。
* **狀態篩選與統計**：提供圓角晶片顯示統計數據（支援音訊、待測試、不支援），並可一鍵篩選列表。
* **主程式協同作用**：點選「套用到主程式」按鈕會自動複製選取的模型 ID 至剪貼簿，便於更新至 `AI meeting-recorder-v7.html`。

## 🚀 快速開始

本工具採用純前端架構，**無需安裝任何後端伺服器**，直接在瀏覽器雙擊開啟即可使用。

### 步驟 1：取得 Gemini API Key
前往 [Google AI Studio](https://aistudio.google.com/app/apikey) 申請免費或付費的 API Key。

### 步驟 2：開啟工具與設定
1. 在瀏覽器中開啟 `gemini-model-tester.html`。
2. 貼上您的 Gemini API Key（密鑰將安全地儲存在您本機瀏覽器的 `localStorage` 中，不會上傳至任何第三方伺服器）。
3. 點擊 **「🔎 列出所有模型」**。

### 步驟 3：測試語音轉寫能力
1. 將測試錄音檔拖放到 **「步驟 2：選擇測試音訊」** 區域。
2. 在下方模型列表中，找到您想測試的模型（例如 `gemini-1.5-flash` 或 `gemini-2.0-flash-exp`）。
3. 點擊 **「🎙️ 測試此模型」**，等待幾秒鐘後即可在卡片中檢視模型轉寫出的繁體中文或英文文字。
4. 測試成功後，點擊 **「✅ 套用到主程式」** 複製該模型 ID。
